# VisioDraw - 专业绘图应用

一款兼容Visio格式的Windows桌面绘图应用，支持流程图、组织结构图、网络图等多种图表类型。

## 功能特性

### 核心功能
- **基础绘图**: 支持矩形、圆形、三角形、菱形等基础图形
- **流程图**: 提供流程、判断、开始/结束、输入/输出、文档、数据库等专用图形
- **连接线**: 支持直线、箭头、双向箭头等连接线
- **文本编辑**: 支持在图形中添加和编辑文本

### Visio兼容性
- **VSDX导入**: 支持打开Visio 2013及以上版本的.vsdx文件
- **VSDX导出**: 支持将绘图保存为.vsdx格式，可在Visio中打开
- **格式保持**: 尽可能保持图形的位置、大小、颜色等属性

### 导出功能
- **图片导出**: 支持导出为PNG、JPEG格式
- **矢量导出**: 支持导出为SVG格式
- **文档导出**: 支持导出为PDF格式

### 编辑功能
- **撤销/重做**: 支持无限次撤销和重做
- **缩放**: 支持画布缩放（10% - 300%）
- **网格**: 支持显示/隐藏网格，便于对齐
- **属性编辑**: 支持编辑图形的位置、大小、颜色、边框等属性
- **右键菜单**: 支持剪切、复制、粘贴、删除、置于顶层/底层
- **快捷键**: 完整的键盘快捷键支持（Ctrl+N/O/S/Z/Y等）

### 模板系统
- **内置模板**: 提供5个常用模板（流程图、组织结构图、网络拓扑图、UML类图、时序图）
- **自定义模板**: 支持将当前文档保存为模板
- **模板管理**: 支持分类浏览、搜索、预览模板

### 打印功能
- **打印预览**: 支持A4、A3、Letter、Legal等纸张大小
- **打印设置**: 支持方向、缩放、边距、份数设置
- **PDF导出**: 支持通过打印功能导出PDF

### 数据连接
- **Excel导入**: 支持导入Excel文件
- **组织结构图生成**: 自动从Excel数据生成组织结构图
- **数据表格生成**: 将Excel数据显示为表格图形
- **字段识别**: 自动识别姓名、职位、部门、上级等字段

### 性能优化
- **防抖节流**: 优化高频操作性能
- **批量处理**: 大文件分批处理，避免阻塞
- **历史记录优化**: 限制历史记录大小，使用深克隆
- **虚拟渲染**: 只渲染可视区域内容

### Visio模具与模板
- **模具支持**: 支持导入Visio VSSX模具文件
- **模板支持**: 支持导入Visio VSTX模板文件
- **内置模具**: 提供基本流程图、基本形状、网络设备等模具
- **模具浏览器**: 可视化浏览和使用模具中的图形

## 技术栈

- **框架**: Electron + React + TypeScript
- **图形引擎**: Fabric.js
- **UI组件**: Ant Design
- **状态管理**: Zustand
- **构建工具**: Vite

## 使用说明

### 创建图形
1. 从左侧图形库中选择需要的图形
2. 点击图形即可添加到画布
3. 或者选择工具栏中的绘图工具，在画布上绘制

### 编辑图形
1. 点击选中图形
2. 在右侧属性面板中修改位置、大小、颜色等属性
3. 拖拽图形可移动位置
4. 拖拽控制点可调整大小

### 文件操作
- **新建**: Ctrl + N
- **打开**: Ctrl + O
- **保存**: Ctrl + S
- **撤销**: Ctrl + Z
- **重做**: Ctrl + Y
- **删除**: Delete

### 视图操作
- **放大**: Ctrl + =
- **缩小**: Ctrl + -
- **适应窗口**: Ctrl + 0

## 注意事项

1. **Visio兼容性**: 目前主要支持VSDX格式的基本图形，复杂图形和高级特性可能不完全兼容
2. **字体**: 建议使用常用字体，避免跨平台字体不兼容问题
3. **大文件**: 超大图形文件（1000+元素）可能影响性能
