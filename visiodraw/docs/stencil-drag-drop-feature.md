# 模具拖拽功能改进文档

## 版本信息
- **版本号**: v1.1.0
- **更新日期**: 2026-02-07
- **作者**: VisioDraw Team

## 功能描述

本版本对 VisioDraw 的模具系统进行了重大改进，实现了拖拽添加图形功能，并大幅提升了模具的视觉效果。

### 主要改进

1. **拖拽功能 (Drag & Drop)**
   - 支持从基础图形面板拖拽图形到画布
   - 支持从 Visio 模具面板拖拽图形到画布
   - 支持在画布任意位置放置图形
   - 拖拽过程中显示视觉反馈

2. **视觉效果改进**
   - 为所有基础图形添加了 SVG 图标
   - 为 Visio 模具添加了专业的图标（网络设备、流程图等）
   - 添加了悬停动画效果
   - 添加了拖拽状态视觉反馈

3. **交互体验优化**
   - 画布在拖拽进入时显示高亮边框
   - 拖拽时显示"释放鼠标添加图形"提示
   - 图形放置位置精确计算

## 使用说明

### 基础操作

1. **从基础图形面板拖拽**
   - 在左侧"基础图形"面板中找到需要的图形
   - 按住鼠标左键拖拽图形到画布
   - 在目标位置释放鼠标即可添加图形

2. **从 Visio 模具拖拽**
   - 切换到"Visio 模具"标签页
   - 展开模具分类（如"网络设备"、"基本流程图形状"等）
   - 拖拽需要的图形到画布

3. **导入自定义模具**
   - 在"Visio 模具"面板切换到"自定义模具"标签
   - 点击"导入 VSSX 模具"按钮
   - 选择本地的 .vssx 文件
   - 导入后即可拖拽使用

### 支持的图形类型

#### 基础图形
- 矩形、圆角矩形
- 圆形、椭圆
- 三角形、菱形
- 直线、箭头

#### 流程图图形
- 流程（矩形）
- 判断（菱形）
- 开始/结束（椭圆）
- 输入/输出（平行四边形）
- 文档、数据库

#### 网络设备
- 服务器
- 路由器
- 交换机
- 防火墙
- 云
- 工作站

## 技术实现

### 核心文件

| 文件 | 说明 |
|------|------|
| `src/types/dragDrop.ts` | 拖拽相关类型定义 |
| `src/hooks/useDragDrop.ts` | 拖拽功能自定义 Hook |
| `src/components/ShapeLibrary.tsx` | 基础图形面板（已添加拖拽） |
| `src/components/StencilBrowser.tsx` | Visio 模具面板（已添加拖拽和图标） |
| `src/components/Canvas.tsx` | 画布组件（已添加放置接收） |

### 关键技术点

1. **HTML5 Drag and Drop API**
   - 使用 `draggable` 属性启用拖拽
   - 使用 `dragstart`、`dragover`、`drop` 事件
   - 使用 `DataTransfer` 传递拖拽数据

2. **SVG 图标系统**
   - 为每种图形类型定义 SVG 图标
   - 使用 viewBox 确保图标自适应
   - 根据模具类别动态选择图标

3. **坐标计算**
   - 考虑画布缩放比例
   - 计算准确的放置位置
   - 图形居中放置于鼠标位置

## 注意事项

1. **浏览器兼容性**
   - 支持所有现代浏览器（Chrome、Firefox、Edge、Safari）
   - IE11 不支持 HTML5 Drag and Drop API

2. **性能考虑**
   - 大量模具时可能影响渲染性能
   - 建议单个模具文件包含不超过 100 个图形

3. **自定义模具限制**
   - 自定义模具仅在当前会话有效
   - 页面刷新后需要重新导入
   - 后续版本将支持持久化存储

## 已知问题

1. **拖拽预览**
   - 在某些浏览器中拖拽预览可能显示不正确
   - 不影响实际功能

2. **移动端支持**
   - 当前版本不支持触摸设备拖拽
   - 后续版本将添加触摸支持
