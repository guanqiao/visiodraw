# 连接点系统功能文档

**版本**: v1.4.0  
**更新日期**: 2026-02-07  
**功能名称**: Connection Points System (连接点系统)

---

## 功能描述

连接点系统为图形提供可连接的位置点，支持智能吸附和动态连接。每个图形可以拥有多个连接点，用于连接线的起点和终点。

### 主要特性

1. **自动连接点生成**: 根据图形类型自动生成默认连接点
2. **连接点可视化**: 悬停或选中图形时显示连接点
3. **状态管理**: 支持已连接/未连接状态显示
4. **位置计算**: 支持旋转后的连接点位置计算
5. **数据持久化**: 连接点数据随图形保存和加载

---

## 使用方法

### 1. 查看连接点

- **悬停显示**: 鼠标悬停在图形上时，自动显示该图形的连接点
- **选中显示**: 选中图形时，持续显示连接点

### 2. 连接点样式

- **未连接**: 白色填充，蓝色边框
- **已连接**: 绿色填充（表示已有连接线连接）
- **悬停**: 蓝色填充（表示可点击连接）

### 3. 默认连接点配置

| 图形类型 | 连接点位置 |
|---------|-----------|
| 矩形/流程图 | 上、下、左、右 |
| 圆形/椭圆 | 上、下、左、右 |
| 三角形 | 三个顶点 |
| 菱形 | 四条边中点 |
| 开始/结束 | 左、右 |

## 技术实现

### 文件结构

```
src/
├── types/
│   └── connection.ts       # 连接点类型定义
├── utils/
│   └── connectionPoints.ts # 连接点工具函数
├── stores/
│   └── canvasStore.ts      # 状态管理（已扩展）
└── components/
    └── Canvas.tsx          # 画布组件（已扩展）
```

### 核心接口

```typescript
interface ConnectionPoint {
  id: string;           // 唯一标识
  x: number;           // 相对X坐标（0-1）
  y: number;           // 相对Y坐标（0-1）
  position: 'top' | 'bottom' | 'left' | 'right' | 'custom';
  isVisible: boolean;  // 是否可见
  isConnected: boolean; // 是否已连接
  connectedLineIds: string[]; // 连接线ID列表
}
```

### 主要函数

- `generateDefaultConnectionPoints(shapeType)`: 生成默认连接点
- `calculateConnectionPointPosition(shape, point)`: 计算连接点绝对位置
- `findNearestConnectionPoint(x, y, shapes)`: 查找最近的连接点
- `updateConnectionPointStatus(shape, pointId, lineId, isConnecting)`: 更新连接状态

---

## 注意事项

1. **性能考虑**: 连接点渲染使用 Fabric.js Circle 对象，大量图形时需注意性能
2. **旋转支持**: 连接点位置计算已考虑图形旋转角度
3. **缩放适配**: 连接点大小不随画布缩放变化，保持固定大小
4. **数据兼容**: 旧版本图形没有连接点数据，会自动生成默认连接点

---

## 限制条件

1. 目前只支持在悬停或选中时显示连接点
2. 连接点位置暂时不支持自定义（后续版本支持）
3. 每个连接点默认只支持一条连接线（可通过配置修改）
