## 任务描述

实现图形连接点管理，支持自动吸附和动态连接。为每个图形定义连接点（上、下、左、右，可扩展），支持连接点可视化、自定义位置和数量。

---

## 任务依赖

- 无（基于现有Canvas系统）

---

## 详细设计

### 1. 数据模型

```typescript
// 连接点位置
interface ConnectionPoint {
  id: string;           // 唯一标识
  x: number;           // 相对图形的X坐标（0-1之间）
  y: number;           // 相对图形的Y坐标（0-1之间）
  position: 'top' | 'bottom' | 'left' | 'right' | 'custom';
  isVisible: boolean;  // 是否可见
  isConnected: boolean; // 是否已连接
}

// 图形扩展属性
interface ShapeWithConnectionPoints extends Shape {
  connectionPoints: ConnectionPoint[];
}
```

### 2. 默认连接点配置

- 矩形/流程图: 4个连接点（上、下、左、右）
- 圆形/椭圆: 4个连接点（上、下、左、右）
- 三角形: 3个连接点（三个顶点）
- 菱形: 4个连接点（四条边中点）

### 3. 功能列表

1. 为每个图形自动生成默认连接点
2. 悬停图形时显示连接点
3. 连接点位置计算（相对转绝对坐标）
4. 连接点数据随图形保存/加载
5. 连接点吸附检测
