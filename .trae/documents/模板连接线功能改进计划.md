# 模板连接线功能改进计划

**版本**: v1.5.0  
**更新日期**: 2026-02-07  
**优先级**: 高  
**预计时间**: 3天

## 任务描述

为模板系统添加连接线支持，使模板可以包含预定义的图形间连接线，并在画布中正确渲染。

---

## 任务依赖

- 连接点系统（已完成）
- 模板系统（已完成）
- Canvas渲染系统（已完成）

---

## 详细设计

### 1. 扩展 Template 类型

```typescript
// src/templates/types.ts
export interface Template {
  id: string
  name: string
  description: string
  category: TemplateCategory
  thumbnail?: string
  shapes: Shape[]
  connectors?: Connector[]  // 新增：连接线数组
  version: string
  createdAt: string
  updatedAt: string
  isBuiltIn: boolean
}
```

### 2. 为内置模板添加连接线

以简单流程图模板为例，添加以下连接线：
- 开始 → 输入数据
- 输入数据 → 处理数据
- 处理数据 → 判断
- 判断 → 显示错误（否分支）
- 判断 → 输出结果（是分支）
- 显示错误 → 输出结果
- 输出结果 → 结束

### 3. Canvas组件添加连接线渲染

新增功能：
- 监听 `connectors` 状态变化，同步渲染连接线
- 支持三种线型：直线(straight)、正交线(orthogonal)、曲线(curved)
- 支持端点样式：无(none)、箭头(arrow)、圆点(dot)、菱形(diamond)
- 连接线随图形移动自动更新位置

### 4. 连接线渲染工具函数

新建 `src/utils/connectorRenderer.ts`：
- `renderConnector()`: 根据Connector数据创建Fabric.js线条对象
- `updateConnectorPosition()`: 图形移动时更新连接线位置
- `createArrowHead()`: 创建箭头端点
- `createDotEnd()`: 创建圆点端点
- `createDiamondEnd()`: 创建菱形端点
- `calculateOrthogonalPath()`: 计算正交线路径点
- `calculateCurvedPath()`: 计算曲线路径点

## 注意事项

1. 连接线ID需要与模板中图形ID对应
2. 考虑性能优化，避免不必要的重绘
3. 连接线需要随图形删除而删除
4. 保持与现有连接点系统的兼容性
