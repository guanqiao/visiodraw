# 模具系统改进开发计划

## 任务概述
改进内置模具系统，实现拖拽添加图形功能，提升视觉效果，对标业界优秀产品。

## 任务列表

### Phase 1: 拖拽功能实现 (优先级: P0)
**任务描述:** 实现 HTML5 Drag and Drop API，支持从模具面板拖拽图形到画布指定位置

**依赖:** 无

**预计时间:** 2天

**完成标准:**
- [ ] 模具项支持拖拽 (draggable=true)
- [ ] 实现 dragstart/dragover/drop 事件
- [ ] 拖拽时显示半透明预览图
- [ ] 画布准确计算放置坐标
- [ ] 支持从ShapeLibrary和StencilBrowser两个面板拖拽

**测试用例:**
1. 从基础图形面板拖拽矩形到画布中央
2. 从Visio模具面板拖拽服务器图标到画布
3. 验证放置位置准确性
4. 验证拖拽过程中预览效果

---

### Phase 2: 模具视觉效果改进 (优先级: P0)
**任务描述:** 为内置模具添加SVG图标，替代当前的纯色矩形占位符

**依赖:** Phase 1

**预计时间:** 3天

**完成标准:**
- [ ] 为基础图形(矩形、圆形、三角形等)设计SVG图标
- [ ] 为流程图图形(流程、判断、文档等)设计SVG图标
- [ ] 为网络设备(服务器、路由器、交换机等)设计SVG图标
- [ ] 模具项悬停时显示阴影和边框高亮
- [ ] 选中状态有明确的视觉反馈

**测试用例:**
1. 验证所有基础图形显示正确的SVG图标
2. 验证网络设备显示专业图标而非矩形
3. 验证悬停效果流畅
4. 验证图标清晰度

---

### Phase 3: 画布渲染增强 (优先级: P1)
**任务描述:** 支持根据模具类型渲染真实图形，而非统一矩形

**依赖:** Phase 2

**预计时间:** 2天

**完成标准:**
- [ ] Canvas组件支持从SVG Path创建图形
- [ ] 网络设备图形使用真实形状渲染
- [ ] 流程图图形使用对应形状(菱形、椭圆等)
- [ ] 保持图形可编辑性(大小、颜色等)

**测试用例:**
1. 拖拽服务器图标到画布，显示服务器形状
2. 拖拽路由器图标到画布，显示路由器形状
3. 验证图形可调整大小
4. 验证图形可修改颜色

---

### Phase 4: 拖拽交互优化 (优先级: P1)
**任务描述:** 优化拖拽过程中的交互体验

**依赖:** Phase 1

**预计时间:** 1天

**完成标准:**
- [ ] 拖拽时鼠标光标变化为 grabbing
- [ ] 画布显示放置区域高亮
- [ ] 拖拽离开画布时取消高亮
- [ ] 添加拖拽动画过渡效果

**测试用例:**
1. 验证拖拽时光标变化
2. 验证画布高亮效果
3. 验证动画流畅度

---

## 技术方案

### 1. 拖拽实现
```typescript
// 模具项添加 draggable 属性
<div 
  draggable
  onDragStart={handleDragStart}
  onDragEnd={handleDragEnd}
>
  {shape.icon}
</div>

// 画布接收拖拽
<canvas
  onDragOver={handleDragOver}
  onDrop={handleDrop}
/>
```

### 2. SVG图标系统
- 使用内联SVG作为模具预览
- 为每种图形定义标准SVG Path
- 支持自定义颜色主题

### 3. 数据扩展
```typescript
interface StencilShape {
  id: string
  name: string
  icon: string // SVG字符串
  width: number
  height: number
  svgPath?: string // Fabric.js Path数据
  category: string
}
```

## 版本信息
- 版本号: v1.1.0
- 更新日期: 2026-02-07
- 影响范围: StencilBrowser, ShapeLibrary, Canvas组件

## 注意事项
1. 保持向后兼容，现有功能不受影响
2. 拖拽功能需要处理浏览器兼容性
3. SVG图标需要考虑暗黑模式适配
4. 性能优化：大量模具时的渲染性能

## 限制条件
1. 暂不支持从外部拖拽文件
2. 复杂SVG图形可能需要简化以适应画布
3. 自定义VSSX模具仍使用默认图标
