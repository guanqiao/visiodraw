## 概述

### 目标

基于现有 v1.3.0 版本，全面增强 VisioDraw 的核心竞争力，使其在功能上接近 Microsoft Visio，在体验上超越同类竞品。

### 总体时间线

```
第1-3周   [阶段六]  智能连接线系统
第4-5周   [阶段七]  对齐与分布系统  
第6-7周   [阶段八]  多页面管理
第8周     [阶段九]  图层管理系统
第9-10周  [阶段十]  高级图形功能
第11-12周 [阶段十一] 数据与协作
```

## 阶段六：智能连接线系统（第1-3周）

### 任务6.1: 连接点系统（优先级：高）- 4天

**任务描述**: 实现图形连接点管理，支持自动吸附和动态连接

**任务依赖**: 无（基于现有Canvas系统）

**详细需求**:
1. 为每个图形定义连接点（上、下、左、右，可扩展）
2. 连接点可视化（悬停时显示）
3. 连接点可自定义位置和数量
4. 连接点数据结构与图形绑定

**完成标准**:
- [ ] 矩形、圆形、流程图图形都有默认连接点
- [ ] 悬停图形时显示可连接点
- [ ] 连接点位置计算正确
- [ ] 连接点数据随图形保存/加载

**测试用例**:
1. 创建矩形，验证4个连接点位置正确
2. 拖拽连接点到画布，验证吸附效果
3. 保存并重新打开文件，验证连接点数据完整
4. 性能测试：100个图形连接点渲染流畅

**相关文件**:
- `src/utils/connectionPoints.ts` (新建)
- `src/components/Canvas.tsx` (修改)
- `src/stores/canvasStore.ts` (修改)

### 任务6.2: 智能连接线（优先级：高）- 5天

**任务描述**: 实现多种样式的智能连接线，支持动态调整

**任务依赖**: 任务6.1

**详细需求**:
1. 支持3种连接线样式：
   - 直线（Straight）
   - 直角线（Orthogonal）
   - 曲线（Curved/Bezier）
2. 连接线自动路由（避开其他图形）
3. 连接线随图形移动自动调整
4. 连接线的箭头样式（单向、双向、无箭头）
5. 连接线文本标签

**完成标准**:
- [ ] 三种连接线样式都能正常绘制
- [ ] 图形移动时连接线自动跟随
- [ ] 连接线可以添加文本标签
- [ ] 连接线样式可配置（颜色、粗细、箭头）
- [ ] 删除图形时自动删除关联连接线

**测试用例**:
1. 创建两个矩形，用直角线连接，验证路径正确
2. 移动其中一个矩形，验证连接线自动调整
3. 切换连接线样式，验证平滑过渡
4. 删除连接的图形，验证连接线自动删除
5. 复杂场景：10个图形互相连接，移动时无卡顿

**相关文件**:
- `src/utils/connectorEngine.ts` (新建)
- `src/components/Canvas.tsx` (修改)
- `src/types/connector.ts` (新建)
