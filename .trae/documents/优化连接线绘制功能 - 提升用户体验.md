## 优化连接线绘制功能 - 提升用户体验

### 任务描述
优化现有的连接线绘制功能，让用户可以更直观、便捷地在图上画连接线。

### 优化目标
1. 支持从图形任意边缘位置开始画线（不只是预定义连接点）
2. 添加连接线拖拽预览效果
3. 增强吸附提示和视觉反馈
4. 支持连接线选择和编辑
5. 优化连接点交互体验

### 任务依赖
- 现有连接线系统（connection.ts、connectorRenderer.ts、connectionPoints.ts）
- Canvas.tsx 画布组件
- canvasStore.ts 状态管理

### 开发计划

#### Phase 1: 增强连接点交互体验
**优先级**: High  
**预计时间**: 2-3小时  
**完成标准**:
- [ ] 鼠标靠近图形边缘时自动显示最近连接点高亮
- [ ] 添加连接点吸附范围扩大（从5px到15px）
- [ ] 连接点悬停时显示 Tooltip 提示
- [ ] 优化连接点视觉效果（放大、发光效果）

#### Phase 2: 实现连接线拖拽预览
**优先级**: High  
**预计时间**: 3-4小时  
**完成标准**:
- [ ] 创建临时连接线预览对象（虚线样式）
- [ ] 实现鼠标拖拽时的实时路径计算
- [ ] 支持三种线型（直线、正交、曲线）的实时预览
- [ ] 拖拽结束时自动吸附到最近连接点

#### Phase 3: 支持从图形任意位置开始画线
**优先级**: Medium  
**预计时间**: 2-3小时  
**完成标准**:
- [ ] 计算鼠标位置到图形边缘的最近点
- [ ] 动态创建临时连接点
- [ ] 支持从图形边缘任意位置发起连接
- [ ] 自动选择最佳连接方向

#### Phase 4: 连接线选择与编辑
**优先级**: Medium  
**预计时间**: 3-4小时  
**完成标准**:
- [ ] 连接线可选中（点击选择）
- [ ] 选中后显示属性面板（颜色、线宽、线型、端点样式）
- [ ] 支持 Delete 键删除连接线
- [ ] 连接线随图形移动自动更新

#### Phase 5: 添加连接线工具到工具栏
**优先级**: Low  
**预计时间**: 1-2小时  
**完成标准**:
- [ ] 在工具栏添加"连接线"工具按钮
- [ ] 选择工具后进入画线模式
- [ ] 支持连续绘制多条连接线
- [ ] 按 ESC 退出画线模式
